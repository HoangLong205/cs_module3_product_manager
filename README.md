# 🛒 Product Manager – Java Web Project

## 📌 Giới thiệu
Dự án website quản lý & bán sản phẩm được xây dựng trong môn học Java Web.  
Người dùng có thể đăng ký, đăng nhập, xem sản phẩm, thêm vào giỏ hàng và đặt hàng.  
Admin có thể quản lý sản phẩm với các chức năng CRUD (Create – Read – Update – Delete).

## 🚀 Công nghệ sử dụng
- **Backend:** Java, JSP/Servlet, JDBC  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** MySQL  
- **Công cụ:** GitHub, IntelliJ IDEA / Eclipse  

## ✨ Chức năng chính
- 👤 Đăng ký / Đăng nhập (Login/Register)  
- 📦 Quản lý sản phẩm (CRUD)  
- 🛒 Giỏ hàng (Cart: thêm, xóa, tính tổng tiền)  
- 🔑 Phân quyền người dùng (User/Admin)

## 🖥️ Hướng dẫn chạy dự án
1. Clone repo về máy:
   ```bash
   git clone https://github.com/HoangLong205/cs_module3_product_manager.git
2. Import vào IDE (Eclipse / IntelliJ).
3. Tạo database MySQL, import file db.sql.
4. Chỉnh DBConnection.java cho đúng config (user/password).
5. Chạy server (Tomcat) → truy cập http://localhost:8080/product_manager.
